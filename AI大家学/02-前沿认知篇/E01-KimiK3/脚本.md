## 【第一部分：它有多强】（0:45-2:30）

先看硬数据，这些数据都来自月之暗面官方技术报告 + Artificial Analysis 等第三方评测。

Kimi K3，2.8 万亿参数。目前全球参数规模最大的开源模型，没有之一。但它不是傻大个——用的是 MoE 混合专家架构，896 个专家，每次推理只激活 16 个，实际干活的参数远小于总参数。

翻译成人话：知识储备极大，但单次干活只调用一小部分，成本和部署门槛可控。

上下文窗口 100 万 Token。大概相当于一口气读完七八本中篇小说，还能记住第一页写了什么。而且原生支持视觉理解——能看图和视频。

好，参数说完了，看成绩单。这几项是我认为最硬、也最经得起查的：

说实话，单看总分，K3 跟最顶级的闭源还有一点点差距。但有两件事必须说：第一，它是开放权重的，Claude 和 GPT 都是闭源的；第二，月之暗面自己也在发布时坦率承认——"整体表现仍落后于最强的闭源模型"。敢公开说自己不如人，这本身就很中国 AI 新势力。

## 【第二部分：怎么做到的】（2:30-4:15）

好，问题来了。凭什么？

DeepSeek 出来的时候大家震惊过一次。这才过了一年半，月之暗面又搞出更大的。他们到底不一样在哪？

答案在底层。杨植麟今年 3 月在英伟达 GTC 上说了一句很硬的话：要推动大模型智能上限的突破，必须对**优化器、注意力机制、残差连接**这些底层基石做重构。K3 干的就是这个。

（画面：Transformer 底座 → 三大重构箭头）

月之暗面回应争议时，披露了支撑 K3 的三项自研底层技术：

**第一，Kimi Delta Attention（KDA），自研混合线性注意力。** 传统 Transformer 的全注意力复杂度是二次方的，文本越长越爆炸。KDA 是一种混合线性注意力——在不同通道上用不同衰减速率管理记忆，长文本效率大幅提升。配合 **Attention Residuals（注意力残差）**，优化多层网络间的信息传递，让 2.8 万亿参数的巨无霸既能稳定训练，推理效率还提升约 25%。

（画面：KDA 注意力示意图——长序列上记忆衰减曲线，关键信息保留、噪声淡出）

**第二，Kimi Linear Tension，自研线性注意力机制。** 解决传统线性注意力处理超长任务时性能衰减的痛点。效果是：上下文窗口扩大十倍，训练成本只同步扩大十倍——这就是长上下文能力的工程底气。

**第三，Moon Clip，全新二阶优化器。** 由 Kimi 首次用到大模型训练。官方说法是：能让 20T 的训练数据跑出 40T 的效果，同等性能下训练成本和算力功耗直接减半。

（画面：三大技术支柱并排——KDA / Linear Tension / Moon Clip，对应 Long Context / Token Efficiency / Agent Swarm）

这三件事叠在一起，带来的结果是：K3 相比上一代 K2，**整体扩展效率提升约 2.5 倍**——同样把算力换成智能，效率高出一大截。

所以"凭什么"的答案很清楚：不是堆钱，是**在沿用近十年的 AI 基础机制上做了系统性重写**。这比单纯把参数做大，值钱得多。

## 【第三部分：为什么全球都紧张】（4:15-5:30）

夸完了，说点更刺激的——为什么这事让大洋两岸都坐不住？

第一个信号来自需求本身。K3 发布 48 小时内，用户请求量远超预估，逼近集群承载极限。月之暗面直接**暂停了 C 端新用户订阅**，把算力全留给付费老用户。业内把这次算力挤兑叫"DeepSeek 2.0 时刻"——你还记得去年 DeepSeek 服务器被挤爆吗？这次更猛。

（画面：服务器负载红条 + "暂停新用户注册"公告截图）

第二个信号，就是开头说的白宫指控。7 月 22 号，白宫科技政策办主任克拉齐奥斯公开说，月之暗面通过蒸馏 Anthropic 的 Fable 来造 K3；财长贝森特威胁用制裁和实体清单应对。

但很快反转。AI 专家内森·兰伯特撰文指出：靠蒸馏根本做不出 K3 这种前沿性能——K3 在 Vals AI 指数排全球第二、Artificial Analysis 排第三、前端代码榜第一。一个独立研究者还补了关键论据：K3 是开放权重的，技术报告全公开，你蒸出来的应该是别人的架构，不是自己的 KDA。

（画面：三条论据依次打勾——① 性能无法靠蒸馏获得 ② 开源技术报告可复核 ③ 时间线对不上）

更值得玩味的是 pattern。今年 6 月，Anthropic 刚指控阿里巴巴"蒸馏攻击"；7 月又指向月之暗面。中国商务部回应：美方"缺乏事实依据、双重标准，是典型的 AI 霸权主义"。说白了，美国的遏制链条，正从"卡芯片"延伸到"卡算法"——你强了，就说你偷。

（画面：时间轴——禁运 GPU → 指控蒸馏 → 实体清单威胁，"从卡芯片到卡算法"）

我的判断：这恰恰说明他们慌了。真要讲理，开放权重的 K3 比任何闭源模型都更好验证。

## 【第四部分：为什么重要】（5:30-6:50）

技术聊完，争议说了。最后一个问题：Kimi K3 到底重不重要？

我觉得很重要，而且不只对中国 AI。

**第一，这是一个趋势信号，不是偶然。**
DeepSeek 出来时，有人说是灵光一现。K3 出来，你不能再这么说了。从 DeepSeek R1、V3，到 Kimi K2、K3，中国 AI 公司正在系统性地逼近、甚至局部超越美国顶级实验室。密度越来越高，不是一次，是趋势。

（画面：时间轴——DeepSeek R1 → V3 → Kimi K2 → K3，密度越来越高）

**第二，开源路线的突围。**
K3 是开放权重的——7 月 27 号完整权重上线，你可以下载、部署、二次开发。而它前面的 Fable 5、GPT-5.6 Sol 都是闭源。一个 2.8 万亿参数的开源模型打到全球第三，给整个开源生态打了一针强心剂。华为昇腾、沐曦、燧原等国产算力已经在适配，vLLM 也提供了生产级支持。这意味着中国的 AI 基础设施正在形成闭环——自己的芯片、自己的模型、自己的框架。

（画面：生态闭环图——国产芯片 → 开源模型 → 部署框架 → 应用生态）

**第三，资本市场的真金白银定价。**
月之暗面 2025 年底估值约 43 亿美元；2026 年 6 月底冲到 315 亿美元；据媒体报道，正启动 Pre-IPO 轮，目标投前估值 500 亿美元，中金、高盛任联席保荐，冲刺港股。半年涨了约七倍。而且它主动说了一句话很有意思——企业业务负责人黄震昕：中国大模型"不该被贴上低价标签"，做出了 SOTA 级模型，就能匹配合理定价权。从"便宜"到"敢定价"，这是一种成熟。

## 【收尾：我的判断】（6:50-7:40）

最后说几句我自己的看法。

K3 不完美。独立测试（Artificial Analysis）显示它的对抗性幻觉率约 51%——你故意问模棱两可的问题，它有一半概率很自信地编答案。但注意，同一基准下 Claude Fable 5 是 54.9%，顶级模型都有这毛病——能力越强，编得越自信。复杂编程上，它跟 Claude 也还有一点差距。

但它证明了一件更重要的事——**中国团队可以在最前沿的底层机制上做原创。** KDA、Moon Clip、注意力残差，不是谁教他们的，是他们自己研究出来的。这才是真正值钱的部分。

（画面：KDA 技术示意图，从月之暗面 logo 发出，连向全球 AI 生态）

从 GPT 到 DeepSeek，从 DeepSeek 到 Kimi，AI 格局正从"一家独大"走向"多极竞争"。而开源模型的崛起，意味着能力不再锁在几家闭源公司手里。对我们普通人、对开发者、对中小企业来说，这是大好事——竞争越激烈，模型越好用，你也能越便宜地用上前沿智能。

1. **定价叙事**：原"比 Claude/GPT 便宜 2-3 倍"不准确。K3 的 API 价是输入 $3 / 输出 $15 每百万 Token，已接近前沿水平（单任务成本约 $0.94 vs GPT-5.6 Sol $1.04）。真实成本优势在**训练端**（2.5 倍扩展效率），不在 API 便宜。已改。
2. **MMLU-Pro 84.7%**：主流实测约 88-89%，原数字偏低且存疑，已改用更硬的榜单（Frontend Code Arena / AA Index / GDPval / BrowseComp）。

4. **"3:1 混合 75%/25% 注意力"**：官方无此说法，已替换为三项自研技术准确表述。
5. **幻觉对比**：原"Opus 5 也是 50%"改为同基准的 Claude Fable 5（54.9%），更准确也更有说服力。
6. **SWE-bench 67.3%**：口径模糊，已改用明确可查的 DeepSWE 67.5% / SWE-bench Verified 75.5% 思路，或干脆以 Frontend Code Arena 为旗舰队形。
